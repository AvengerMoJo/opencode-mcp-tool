# opencode-mcp-tool

A collection of tools and utilities for working with the opencode-mcp framework.

## Features

- Various utility functions and tools
- Built to help with development tasks
- Follows TypeScript best practices

## Usage

```bash
# Build project
npm run build

# Run development server
npm run dev
```
